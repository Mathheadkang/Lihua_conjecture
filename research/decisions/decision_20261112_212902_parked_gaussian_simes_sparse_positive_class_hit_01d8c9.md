Set aside: when every positively correlated class is small, no fixed prior hits the sparse crossings in proportion, and this lemma reduces (up to a small error) to the sparse-crossing fixed-level cap with value one quarter, which is set aside for the same reason. Splitting into nonpositively correlated classes repeats the proportional-hitting problem one level down, and no Simes bound for negatively correlated Gaussians is known. What would get past it: a collective maximal inequality charging the supremum over thresholds once for weakly correlated, mixed-sign configurations; the same tool would also settle the sparse cap.
