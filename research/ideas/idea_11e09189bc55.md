Concrete self-contained route for the promoted conditional calibration, without using an unapproved compound-p theorem as a black box. Source attribution: Barber and Samworth, arXiv:2507.21465v2, PDF Theorem 1 p.6, Appendix A.2 pp.27–30 (local PDF SHA c3dab0cf028a2099e23bb2c9e451f9a296dac5127303a7451da3b0c70715d6e9). The source suggests the actual-BH reverse-hazard decomposition. Re-prove all used steps here; the sharper source constant is unnecessary.

1. For independent compound p-values at nominal alpha, condition on nonnull coordinates. Define k_i=max{k: i + A_nonnull(alpha k/N)>=k}, k_i>=i, and I=max{i: C_null(alpha k_i/N)>=i}. Prove exactly R=k_I and V=I with largest nonstrict BH ranks, including ties and I=0. Let a_i=P(I=i|I<=i); then P(I=i)=a_i product_{j>i}(1-a_j). Product association (proved by induction from the scalar rearrangement inequality) gives a_i<=P(C_null(alpha k_i/N)>=i). The null Bernoulli count has mean<=t_i=alpha k_i.

2. Replace any independent Bernoulli sum of mean<=t by a Poisson(t) variable ONLY in convex increasing stop-loss expectation. This follows elementarily: for convex phi on nonnegative integers, phi(k)>=phi(0)+k(phi(1)-phi(0)), so Bernoulli(p)<=cx Poisson(p); independence and an extra Poisson increment preserve the order. Thus
P(S>=i)<= beta_i(t)=E[(Poisson(t)-i+1)_+].
No Poisson tail comparison theorem or Hoeffding extremality is assumed. beta_i(t)=t-i+1+exp(-t) sum_{k=0}^{i-2}(i-1-k)t^k/k!, and beta_i is increasing.

3. Bound the reverse-hazard objective sum_i (i/t_i) a_i product_{j>i}(1-a_j) by dynamic constants. Start c_1=1 and use
c_i = c_{i-1} + sup_{0<t<i/c_{i-1}} (i/t-c_{i-1})_+ beta_i(t).
An upper rounded value suffices at each step. A tiny exploratory floating grid suggests c_30 approximately 1.883, but this IS NOT certified and is not proof. The needed finite gate is only c_30<=19/10. Prove it with an explicit exact-integer/rational interval certificate over all t, not sampled points: on [l,h] with l>0 use (i/l-c)_+ beta_i(h); near zero use beta_i(h)<=h^i/i!, giving i h^(i-1)/i!. Enclose exp(-h) rigorously with positive Taylor sums for exp(h) and a geometric remainder, then invert. All rounding outward. Adaptive subdivision can reduce cost. Check every interval and publish reproducible rational endpoint evidence. If that certificate fails, stop rather than silently adjust the lemma.

4. Extend the finite prefix analytically. For i>30 and c>=19/10, Chernoff and the ratio bound for h_k(t)=exp(-t)(et/k)^k imply beta_i(t)<=h_i(t)/(1-t/i), for t<i/c. Hence (i/t-c)beta_i(t)<=(i/t)h_i(t)<=(19/10) r^i with r=exp(9/19)/(19/10)<17/20. The last strict inequality can itself be certified by a short rational Taylor remainder. The remaining total is at most (19/10)(17/20)^31/(1-17/20)<1/10, so the full constant is <2. This uses a coarse finite margin, not constant optimization.

5. For the actual conditional lemma, if q K>=1 or K=infinity the bound is trivial. Otherwise transform each coordinate into K P_i for P_i<=q and 1 for P_i>q. Show aggregate compound validity at every t in [0,1], conditional independence, and exact original BH rank/rejection/null-label equality at levels q and qK. Apply the newly proved constant-2 independent-compound result to the transformed coordinates. Measurability uses the rational threshold set plus endpoint q and regular conditional CDFs. This avoids paying the sum of individual level suprema.

This route is a candidate executable proof, with an explicit finite certification gate. The floating diagnostics are not proof. It establishes only the finite conditional aggregation tool; the unrestricted Gaussian envelope, conditioning choice and uniform singular/noise removal remain open. No new completion root.
