Route 1 of the researcher-authorized parallel round of 12 November 2026. UNPROVED draft direction; nothing below is verified.

**Core idea.** The approved directional-entropy bound (directional_entropy_one_sided_fdr_bound) already gives the target whenever the oriented null directional entropy is o(sqrt(log(1/q))). Its only weakness is that groups must lie on exactly the same ray. Replace exact grouping by angular clustering at scale c/U, U = S^{-1}(q), then replace the one-scale entropy by a multi-scale (generic-chaining) charge, continuing idea_c5bacf260246 (whose first test CH-2 was never run).

**External input (anti-saturation).** (a) Angular stability: at threshold scale U, two directions at angle delta change the relevant null likelihood ratio by a factor exp(O(U delta)), bounded for delta <= c/U. (b) Talagrand's generic chaining for the multi-scale charge.

**Lemmas to aim for.**
- L1 (approximate grouping): the entropy bound holds, with a universal constant loss, for groupings whose groups have angular diameter <= c/U. First check: locate exactly where the approved proof uses "same ray".
- L2 (rare-cluster cap): null clusters of total mass < q^C contribute O(q) in total. Caution: the one-null staircase (idea_75d71c7756b4) attains the harmonic factor for a single null, so L2 must use competition between clusters through the single scalar BH cutoff, not a per-cluster bound. Candidate tool: approved conditional sub-Poisson calibration (hypotheses not yet checked).
- L1 + L2 give a dimension-free C q log(1/q) bound (milestone; no such unrestricted bound was found in the literature). CH-2 chaining on top is needed for q sqrt(log(1/q)).

**Saturation check before any plan.** In the zero-mean independent case the leftover charge must be an explicit entropy/chaining quantity, not the FDR itself.

**Failure criterion.** A family with many clusters at angle about 1/U and FDR/(q log(1/q)) unbounded refutes L2; then this route yields only a structured class.
