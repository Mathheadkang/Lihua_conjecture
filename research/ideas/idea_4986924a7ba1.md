Unverified agent reasoning (plan stage, 12 November 2026). When every positive class of Sigma has size at most m, the fixed prior pi gives hitting mass at most E_pi|S| times the largest pi-coverage weight on A, so h is small whenever the BH set is sparse and the coverage weights are spread out; the lemma then asks P(E minus D) <= 1/4 + o(1), a sparse cap with an explicit value. A natural mixed-sign repair partitions [N] into chi classes with pairwise nonpositive correlations (a colouring of the positive-correlation graph) and pigeonholes a rank-k crossing into some class j with count >= k n_j/N. It fails twice: (i) the proportional count k n_j/N can be below 1, so the per-class Simes event needs max(1, k n_j/N) hits, the same proportional-hitting obstruction one level down; (ii) chi is unbounded, and the project library has no Simes bound for nonpositively correlated Gaussian vectors (only lib_chi2024_positive_gaussian_simes). A route through negative classes would need such a bound plus a collective (supremum-over-thresholds) argument, which is the missing ingredient recorded in idea_f2b3f28a7ab4.
