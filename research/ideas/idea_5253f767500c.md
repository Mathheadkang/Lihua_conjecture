This is a draft obstruction to a uniform PATHWISE positive-flow budget, not a counterexample to the main expected FDR order bound. It was obtained while evaluating the latest free-envelope, exact-gradient and collective-rank-entropy ideas. No main-target plan was manufactured from the missing Gaussian transfer.

Fix any 0<q<1/2 and N=2m. Let S=barPhi, u_h=S^{-1}(qh/N), and choose original means theta_h=1 at odd indices and theta_h=0 at even indices, with covariance I_N. Original true labels stay fixed throughout the following common-shift path; the shifted counted FDP is not asserted to use the shifted model's changing true-null labels. Put a_h=1-h/(N+1) and z_h=u_h+a_h. Both u_h and a_h strictly decrease, so z_1>...>z_N and 1>a_1>...>a_N>0. For T(t)=z-t*1_N, rank h qualifies exactly when t<=a_h. Consequently the ordinary largest-rank BH path as t decreases from 1 to 0 has every rank 0,1,...,N in order.

For prefix counts V_h and f_h=V_h/h (f_0=0), a null entry at h>=2 has increment (h-V_h)/[h(h-1)]; an alternative entry at h>=2 has increment -V_h/[h(h-1)]. The first alternative has increment zero. With these alternating labels V_(2k)=k, so the positive variation along this COMPLETE actual record path is

$$
P_m=\sum_{k=1}^m\frac{1}{2(2k-1)}=\frac12 H_{2m}-\frac14 H_m=\frac14\log N+O(1).
$$

Thus for any fixed q and finite C, sufficiently large N violates a proposed deterministic bound P_m<=C[1+S^{-1}(q)]. This is not merely an upper bound produced by splitting jumps: every positive prefix step really occurs on the constructed common-shift BH path. All strict score-order and margin-order inequalities persist on a nonempty open neighborhood, which has positive probability under the specified independent finite Gaussian model. Gaussian probabilities of these neighborhoods may shrink with N. No lower bound for EXPECTED positive variation follows, and actual independent one-sided BH FDR is not contradicted.

The general deterministic prefix allocation (f_r-f_s)_+<=sum_(h=s+1)^r(f_h-f_(h-1))_+ therefore cannot close a dimension-uniform proof without event-sensitive Gaussian averaging. A prospective plan must supply a new summable Gaussian estimate retaining the actual record/cascade masks or work with a different signed object; replacing that estimate by a free threshold envelope is excluded by idea_d353cd54790b. The deterministic harmonic entropy in idea_e79e09e7bbef does not already supply this transfer.
