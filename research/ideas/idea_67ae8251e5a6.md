Let F=E[FDP]>0 and define the finite joint probability mu(i,dg)=1{i is a true null and is rejected} gamma(dg)/(R F), with zero density when R=0. Its Gaussian marginal is Q=(FDP/F)gamma and its index marginal is pi. Relative entropy decomposes exactly as D(mu||pi x gamma)=D(Q||gamma)+I_mu(I;G)=log(N/F)-E_mu log R-D(pi||Unif_N). Given (I,R), the selected Gaussian coordinate is at least u_R-theta_I. Tail-event relative entropy and the fact that R is a function of G therefore give only F <= q exp{H_mu(R|I)-D(pi||Unif_N)}. No new uniform main bound follows unless the remaining rank information is actually controlled or cancelled. Large mutual information alone is not a refutation of a more exact cancellation: the log(N/R) term can have the same leading order.

A finite legal diagnostic rules out controlling H_mu(R|I), or its dyadic-rank analogue, by q alone. Fix 0<q<1/2, an integer L>=2, N=2^L, r_0=1 and r_j=2^j. There is one true null T_0=G_0, with G_0 independent of a standard normal Z. Alternative block j has r_j-r_{j-1} identical statistics T=Z+theta_j, where theta_j=u_{r_j}-c_j, u_r=normal-survival-inverse(qr/N), and -1=c_1<c_2<...<c_L=0 are chosen so that Phi(c_{j+1})-Phi(c_j)=m/(L-1), m=Phi(0)-Phi(-1)>0. Every theta_j>0; all variances are one, with a valid singular covariance. The means decrease with j, so every block endpoint is an actual ordered BH rank. After setting the null p-value to zero, the actual largest BH rank is R^0(Z)=1 below c_1, and otherwise max{r_j: Z>=c_j}. A qualifying rank inside a tied block implies its endpoint qualifies, so no intermediate crossing was substituted.

The ordinary leave-one-out equivalence says the null is selected exactly when p_0<=qR^0/N, and then R=R^0. Independence gives F=q/N. Under mu the Z marginal remains exactly standard Gaussian, since integrating the null contributes (qR^0/N)/(R^0 F)=1. Therefore H_mu(R|I)=H(R^0(Z)) >= m log((L-1)/m), which diverges with L; the dyadic rank variable retains these same distinct ranks. Here pi is concentrated at the only true null, so D(pi||Unif_N)=log N. Thus this diagnostic does not refute the full entropy inequality, a suitably compensated rank-entropy bound, or the main target. The attempted planning pass found no new executable cancellation and wrote no replacement plan.
