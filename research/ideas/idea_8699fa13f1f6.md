Scoped necessary-condition derivation to independently verify, not an established project theorem or a counterexample. Let B_s(t) be worst-case all-null Gaussian BH rejection probability over all finite unit-diagonal covariance models of test type s. Fix any local all-null m-test model whose rejection probability at level t is p. Form M independent Gaussian copies; the full model has Mm tests, all null. If q/M>=t and any local block rejects at level t, its local qualifying rank r has p_(r)<=tr/m<=q r/(Mm), so the SAME rank r qualifies in the actual full largest-rank BH procedure. Thus the global all-null rejection probability is at least 1-(1-p)^M. This is an event implication, not a replacement of global BH by blockwise optima. If B_s(q*)<=b<1 at even one fixed q*, then for t<=q*/2 and M=floor(q*/t), p<=1-(1-b)^(1/M)<=-log(1-b)/M<=2[-log(1-b)]t/q*. Consequently any dimension-uniform upper bound tending to0 as q->0, including the project's order target, would imply a universal small-level linear all-null Simes bound B_s(t)<=C_s t. Conversely an unbounded all-null ratio B_s(t)/t would force B_s(q)=1 for each fixed q by replication and would refute any vanishing universal bound. NO such Gaussian counterfamily is supplied here; finite inflation above t alone is insufficient. This amplification cannot be transferred to mixed-label FDR by adding blockwise FDPs, because other blocks can dilute false discoveries. Primary literature checked for context: Chi–Ramdas–Wang, Multiple testing under negative dependence, author2024PDF https://www.math.uwaterloo.ca/~wang/papers/2024Chi-Ramdas-Wang-BJ.pdf §3.3 Remark8 (printedp11) discusses a universal linear bound for arbitrary Gaussian-dependent Simes p-values as open; its Theorem8 negativesign bounds do not establish the arbitrarycovariance case. Their Gaussian-dependent p-values concern one-sided Gaussian copulas; Remark11 explicitly separates two-sided absolute-Gaussian p-values. This necessary condition is a potential diagnostic of the main frontier, not a new claimed solution or an assumption for ongoing clone proofs.
