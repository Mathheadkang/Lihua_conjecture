Concrete UNFINISHED test family, not a counterexample. Let B=B(q) (e.g. ceil(q^{-c})), independent standard factors W,Z_1,...,Z_B and independent residuals. Equal block weights1/B; in blockj take the finite one-factor source design from lei2026_one_sided_fdr_lower (or two-sided source design separately) at local alpha=q/B and null loading r(q). Retain source deterministic means and type weights but replace every non-null source loading -Z_j by -epsilon(q) Z_j-sqrt(1-epsilon(q)^2)W (sign-adjust any positive source loading analogously), so each non-null remains variance1 and primary gates are strongly correlated between blocks. Null coordinates remain theta0+r Z_j+sqrt(1-r²)epsilon_ji (composite shifts allowed only when specified). This is an exactly jointly Gaussian factor+diagonal model with B+1 factors. Endpoints: epsilon1 recovers synchronized independent blocks whose background primary caps obstruct naive local-FDR summation (idea_11028fd850f5); epsilon0 makes nulls independent of the shared non-null gate and should not supply the adversarial mechanism. Intermediate epsilon(q), possibly ~1/sqrt(log1/q), with r≪epsilon and B growing, is unanalysed. Required check: derive the GLOBAL population BH crossing sum_j F_{Z_j,W}(t)/B=t/q, never add independent local FDRs. Determine whether correlated primary gating can evade geometric suppression without losing null/signal coupling; finite-N transfer, ties, and simultaneous q,B,r,epsilon limits must be proved before NOT can pass. Source means/type arrays may require recalibration when non-null loadings change; retaining them is a precisely specified first probe, not a presumed least-favorable design.
