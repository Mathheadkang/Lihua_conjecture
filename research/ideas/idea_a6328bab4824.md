## Observation and scope
A bounded local diagnostic found no violation of the finite-q inequality in directional_entropy_one_sided_fdr_bound among 480 model-level pairs. This is a floating-point diagnostic, not a proof or a certified interval computation. No counterexample candidate was written. The 96 model configurations were generated by Python Random(267114), 16 for each m=1,...,6; they are deterministic once seeded, but are not exhaustive over these dimensions. Each is evaluated at q in {0.001,0.01,0.05,0.2,0.49}.

## Models and grouping
All models have d=1 and loadings a_i=s_i in {-1,+1}, hence r_i=1 and gamma_i=0. For each m and k=0,...,15 the first m0=1+(k mod m) coordinates are null, with means sampled from [0,0,-0.2,-1,-3]; all other means are sampled from [0.05,0.3,1,3,8] and are alternatives. Loadings are sampled from [-1,+1]. The null grouping has one group for each sign that occurs among nulls. Its mass is the number of nulls of that sign divided by ALL m tests. Thus the masses sum to pi0=m0/m; opposite signs are separate groups, whose projections Z and -Z are perfectly anticorrelated. No null-only renormalization is used.

## Calculation
For each i and each BH rank j=1,...,m, compute the real breakpoint z=(Phi^{-1}(1-qj/m)-theta_i)/s_i. The largest-rank BH rejection count and FDP are constant on each open interval between successive breakpoints. Evaluate at an interior point and sum FDP times the Gaussian probability of that interval. Endpoints have probability zero. The compared bound is min(1,q*(1.5*pi0+sum_h pi_h*log(1/pi_h))), since all gamma_i are zero. NormalDist.inv_cdf and math.erfc use standard floating point; there are no certified error enclosures. The reporting threshold was FDR>RHS+1e-12. The largest observed FDR/RHS was 0.666666667. This does not establish the bound for the continuum of small models, loadings r_i<1, higher factor dimensions, or q tending to zero.

## Reproduction source
```python
from statistics import NormalDist
from math import erfc,sqrt,log,inf
from random import Random
import time, resource, sys
started=time.perf_counter()
rng=Random(267114); norm=NormalDist()
def cdf(x): return .5*erfc(-x/sqrt(2))
def tail(x): return .5*erfc(x/sqrt(2))
def prob(a,b): return tail(a)-tail(b) if a>=0 else cdf(b)-cdf(a)
records=[]
for m in range(1,7):
    for k in range(16):
        m0=1+k%m
        signs=[rng.choice([-1,1]) for _ in range(m)]
        theta=[rng.choice([0.,0.,-.2,-1.,-3.]) for _ in range(m0)]+[rng.choice([.05,.3,1.,3.,8.]) for _ in range(m-m0)]
        masses=[sum(s==v for s in signs[:m0])/m for v in [-1,1]]
        coeff=1.5*m0/m-sum(x*log(x) for x in masses if x)
        for q in [.001,.01,.05,.2,.49]:
            cuts=[norm.inv_cdf(1-q*j/m) for j in range(1,m+1)]
            edges=sorted(set((u-t)/s for u in cuts for t,s in zip(theta,signs)))
            bounds=[-inf]+edges+[inf]; fdr=0.
            for lo,hi in zip(bounds[:-1],bounds[1:]):
                z=hi-max(1.,abs(hi)) if lo==-inf else lo+max(1.,abs(lo)) if hi==inf else (lo+hi)/2
                ps=[tail(t+s*z) for t,s in zip(theta,signs)]
                rank=max([0]+[j for j,p in enumerate(sorted(ps),1) if p<=q*j/m])
                if rank:
                    false=sum(p<=q*rank/m for p in ps[:m0])
                    fdr+=prob(lo,hi)*false/rank
            rhs=min(1.,q*coeff)
            records.append((fdr/rhs,fdr,rhs,m,m0,q,signs,theta))
print('Models and levels checked:',len(records))
for m in range(1,7):
    b=max((r for r in records if r[3]==m),key=lambda r:r[0])
    print('m=%d max FDR/RHS=%.9f FDR=%.9g RHS=%.9g m0=%d q=%g signs=%s means=%s' % (m,b[0],b[1],b[2],b[4],b[5],b[6],b[7]))
print('Violations with margin greater than 1e-12:',sum(r[1]>r[2]+1e-12 for r in records))
usage=resource.getrusage(resource.RUSAGE_SELF)
print('Python:',sys.version.replace('\n',' '))
print('Platform:',sys.platform)
print('Elapsed_seconds:',format(time.perf_counter()-started,'.6f'))
print('CPU_user_seconds:',format(usage.ru_utime,'.6f'))
print('CPU_system_seconds:',format(usage.ru_stime,'.6f'))
print('Peak_RSS_platform_units:',usage.ru_maxrss)
```
