For the native reproof's zero-loading case, the source needs barPhi(sqrt(pi/2))>1/10. This can be certified without a numerical normal-CDF lookup. Put x=sqrt(pi/2). For u>=0, exp(-u)<=1-u+u^2/2; integrate with u=t^2/2 on [0,x]. Since x/sqrt(2pi)=1/2, barPhi(x)>=pi/24-pi^2/320. The polynomial f(p)=p/24-p^2/320 is increasing on [157/50,4]. Using 157/50<pi<4 gives f(pi)>f(157/50)=240053/2400000>1/10. Hence q<=1/10 implies U=barPhi^{-1}(q)>sqrt(pi/2), so 1<=1/2+U/sqrt(2pi). This is a local constant check for the existing exact Statement, not a changed q range or a proof of the whole lemma; fresh verification remains required.
