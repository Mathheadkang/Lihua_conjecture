Draft analytic candidate against the GENERAL constrained completion certificate, beyond the row recipe (R) already refuted. Independent verification required; not a main-FDR counterexample.

Fix any q in (0,1/2), pi0=pi1=1/2, beta=10, eta=(q/2)exp(-beta), r=1-eta, alpha=log(2/q-exp(-beta)), D=alpha*r-beta*eta>0. Then root s=1 solves (1/2)e^{-beta s}+(1/2)e^{alpha s}=1/q. Set even N, z_N²=2c log N with c=1/100 (or sufficiently small fixed c), rho_N=lambda/z_N². NULLS have T_i=-beta/z_N+sqrt(rho_N)W+sqrt(1-rho_N)epsilon_i; ALTERNATIVES are T_j=alpha/z_N+epsilon_j, all independent eps and W. Sigma_N=diag((1-rho_N)I_null+rho_N J_null,I_alt), B=I. Exact PD unit diagonal; actual factor dimension1.

Conditional on W, A=-beta+sqrt(lambda)W and limiting Gaussian tail ratios at threshold s z_N are exp(A s-lambda s²/2) for nulls and exp(alpha s) for alternatives. The stable first BH root solves 0.5 exp(A s-lambda s²/2)+0.5 exp(alpha s)=1/q. Its FDP limit is g(A,lambda)=q*0.5 exp(A s-lambda s²/2)=1-q*0.5 exp(alpha s). On W localized near A=-beta the root is unique/compact and smooth. Conditional empirical-CDF or rank-count concentration at polynomial ranks should justify the GLOBAL BH maximum (not a population/local root alone); choose c small so thresholds dominate N^-1/2 errors, and bound rare W tails before the lambda expansion.

Independent root differentiation by the author gives E g(-beta+sqrt(lambda)W,lambda)=eta+(lambda/2)G0+o(lambda), where G0=alpha*r*eta²/D³ *[2alpha*r*(beta-1)+beta*eta*(alpha+2-beta)]>0. This includes the NULL residual-variance drift. For beta10, alpha>=log(4-exp(-10)) and tiny eta make the bracket positive for every fixed q<1/2. Check the factor1/2 and all limit steps. Expected finite-N FDR gain should then have liminf>=lambda G0/4 for sufficiently small fixed lambda.

Gamma_N=diag(J_null,I_alt) is a valid PSD correlation completion with EXACT SAME alternative block as Sigma_N. In the fixed-alt path, only null-null off-diagonals vary, so the exact secant gives tr(Gamma_N K_N)=[B_N(Sigma_N)-B_N(I)]/rho_N, hence liminf tr(Gamma_N K_N)/log N>=cG0/2>0. If verified, this refutes even the general constrained dual trace bound (not merely an explicit Schur/row construction). It uses the specific kernel computed at Sigma_N paired with a different admissible completion Gamma_N. The actual covariance-specific scalar gain remains finite; the model lies in the already covered one-common-factor class and does not refute the sharp FDR conjecture. Formal target and graph status untouched.
