Reuse [the independently verified iid equal-weight frozen-ray theorem](../assets/gaussian_frozen_ray_independent_equal_weights.md), rather than duplicate it. For the two-level field Z_ij=sqrt(a)G_i+sqrt(1-a)G_ij with uniform leaf weights, a=0 gives iid standard normals over all b1*b2 leaves; a=1 gives b2 identical copies of each independent G_i, so the likelihood-ratio average equals the iid b1 average exactly. If b2=1, the b1 coordinates are mutually independent standard normal for every a in [0,1], since each uses a disjoint pair (G_i,G_i1). Thus both target inequalities on all these boundaries follow with precisely the approved constants 9 and150; K=1 is already included in that theorem. No limit interchange, constant depending on branching or new source theorem is needed.

This is a draft reuse observation, not an independent proof of the entire tree target and not a new goal. In particular b1=1 with b2>1 and 0<a<1 remains the equicorrelated cluster family; arbitrary interior a and growing branchings remain unproved. Any tree proof that actually uses the approved iid theorem must declare that dependency through the native workflow. This observation neither changes statements nor overrides the required counterexample search.
